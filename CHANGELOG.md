# Changelog / 更新记录

## 1.1.0

- Instant English / Simplified Chinese switching, including status, validation, tray menus and administrator-helper messages.
- A per-user installer and portable package with the pinned original Sarab driver, plus guided requirements checks, manual-restart preparation and explicit driver install/removal.
- Bilingual repository documentation, visible original-author credits and preserved licenses.
- Generic fresh-install defaults; no developer settings, private coordinates or logs in release artifacts. Existing local profiles are preserved on upgrade.

新增即时中英切换、可分享安装包与安装引导、原作者贡献展示和中英双语文档。新安装使用未应用的通用示例，升级保留已有配置。
